# Repository structure

- `phase1_eda_dashboard/`: Phase 1 exploratory dashboard.
- `streamlit_release/`: Phase 1 hosting entry point and bundled source data.
- `phase2/`: modelling notebooks, shared source, results and reproducibility.
- `phase3/`: integrated FastAPI backend, Streamlit frontend, fitted artifacts, offline export tools, tests and technical documentation.
- `deployment/`: historical location; README points to Phase 3.

Phase 1 and Phase 2 paths are preserved. Raw data is needed for offline reproduction, not Phase 3 inference.
